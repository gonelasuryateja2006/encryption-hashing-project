Foundations

What is Encryption? What is Hashing?

What is Encryption?

Encryption converts readable plaintext into ciphertext with an algorithm and key. Authorized users can decrypt ciphertext back into the original plaintext with the correct key.

What is Hashing?

Hashing converts input data into a fixed-length hash value. It is designed to be one-way so the original input cannot be recovered from the hash.
