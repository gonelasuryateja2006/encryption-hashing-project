# 🔐 Encryption and Hashing Techniques

## 🚀 Project Overview

Encryption and Hashing Techniques is an interactive browser-based cybersecurity project designed to demonstrate fundamental concepts of encryption, decryption, and hashing.

The project provides a simple and user-friendly interface where users can explore different cryptographic techniques directly in their web browser without requiring a backend or database.

## 🎯 Objective

The main objective of this project is to provide an interactive learning platform for understanding various encryption and hashing techniques through practical demonstrations.

The project covers both classical encryption algorithms and modern cryptographic techniques.

## 📊 Dataset Information

This project does not require any external dataset.

All encryption, decryption, and hashing operations are performed directly in the browser using JavaScript and the Web Crypto API.

## 🔬 Encryption Algorithms

### 🔄 Caesar Cipher

Caesar Cipher is a classical substitution cipher where each character is shifted by a fixed number of positions in the alphabet.

### 🔑 Vigenère Cipher

Vigenère Cipher is a classical polyalphabetic substitution cipher that uses a keyword to encrypt and decrypt text.

### 🛡️ AES-256-GCM

AES-256-GCM is a modern authenticated encryption algorithm that provides confidentiality and data integrity.

The implementation uses:

- AES-256-GCM
- PBKDF2
- SHA-256
- Random salt
- Random IV

## #️⃣ Hashing Algorithms

### 🔒 SHA-256

SHA-256 is a cryptographic hash function that generates a 256-bit hash value.

It is widely used in modern security applications.

### ⚠️ MD5

MD5 is a legacy hashing algorithm included in this project for educational purposes.

MD5 is considered insecure for security-sensitive applications and should not be used for passwords or modern security systems.
